# Tastepin QA 이슈

최초 실패 기록은 보존하고 수정 뒤 재검증 결과를 덧붙인다.

## 처리 기준

- 번호는 QA-001부터 붙이며 재사용하지 않는다.
- 데이터나 권한 손상은 긴급, 핵심 기능의 실패는 높음, 우회 가능한 불편은 보통으로 둔다.
- 상태는 확인 필요, 수정 대기, 수정 중, 재검증 대기, 완료, 보류 중 하나다. 결함이 아니거나 중복이면 완료 사유와 관련 번호를 남긴다. 보류할 때는 이유와 다시 볼 조건을 적는다.
- 수정한 코드로 원래 재현 조건과 영향받는 동작을 확인한 뒤 완료한다. 다시 발생하면 기존 번호를 연다.
